## Overview

This repository collects lightweight, interactive reviewers for IT subjects. Each reviewer is designed to run directly in the browser, making it easy to study from GitHub Pages or by opening the HTML file locally.

## Quick Start

1. Clone or download this repository.
2. Open a reviewer folder, such as [`Networking 2`](Networking%202/).
3. Launch [`index.html`](Networking%202/index.html) in your browser.

```text
IT-Subjects-Reviewer/
├─ README.md
└─ Networking 2/
   ├─ index.html
   └─ NetworkingTwoBeginnerGuide.jsx
```

## Notes

- The reviewers are built for quick studying and exam review.
- GitHub Pages can host these files without installing dependencies.
- More subjects can be added as separate folders following the same structure.
